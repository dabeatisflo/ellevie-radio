# ellevie Studio Android

Private Android WebView-app voor `https://studio.ellevie.fr/studio`.

- dezelfde login en hetzelfde wachtwoord als de webversie;
- voornaam per radiomedewerker;
- automatische actualisering om de drie seconden;
- voiceclip-weergave en antwoorden met Enter;
- pushmeldingen met een aan/uit-schakelaar;
- gespreksslot van tien minuten tegen dubbele antwoorden.

De installeerbare Android-build wordt gemaakt met het EAS-profiel `preview`.
